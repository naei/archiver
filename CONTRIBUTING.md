# Contributing to Archiver

Thanks for contributing. Archiver is a small project with one maintainer, so the rules are short.

Pull requests are welcome. The [Development](README.md#development) section of the README explains how to run the project and integrate a platform or a language.

## Contribution terms

By opening a pull request, you agree to these terms:

- You keep ownership of your work.
- You confirm that you have the right to submit it.
- You allow the maintainer, Lucas Pantanella, to use it in Archiver and its future versions, including under a different license if the project ever changes its license.
- If your contribution includes third-party work, identify its source, license and any other restrictions you are aware of in your pull request.
